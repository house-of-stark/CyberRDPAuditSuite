# Analysis Results

This directory contains the results of various security scans and tests performed by the CyberRDP Audit Suite.

## Directory Structure

- `reports/` - Contains detailed security assessment reports
- `test_reports/` - Contains test execution reports and logs
- `logs/` - Contains log files from test executions

## File Naming Convention

Report files typically follow this naming pattern:

```
[test_type]_[target]_[date]_[time].json
```

Example: `rdp_bluekeep_127.0.0.1_20250623_190236.json`

## Notes

- These files are generated automatically by the CyberRDP Audit Suite.
- Do not edit these files manually as they may be overwritten by the tool.
- For more information about the tests and how to interpret the results, refer to the main documentation.

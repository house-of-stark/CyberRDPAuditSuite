# Security Assessment Reports

This directory contains comprehensive security assessment reports generated by the CyberRDP Audit Suite.

## Report Types

- **HTML Reports**: Interactive web-based reports with detailed findings
- **JSON Reports**: Machine-readable report data for further analysis
- **Log Files**: Detailed execution logs for troubleshooting

## File Naming Convention

Report files typically follow this pattern:

```
rdp_security_report_[target]_[timestamp].[format]
```

Example: `rdp_security_report_192.168.1.100_20250617_190145.html`

## Understanding the Reports

- **HTML Reports**: Open in any web browser for an interactive view of the security assessment.
- **JSON Reports**: Can be processed by other tools or imported into SIEM systems.
- **Log Files**: Contain detailed execution information for troubleshooting.

## Notes

- Reports are generated automatically during test execution.
- Historical reports are preserved with timestamps for tracking changes over time.
- Sensitive information may be included in these reports - handle with appropriate security measures.

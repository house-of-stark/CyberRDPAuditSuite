# CyberRDP Audit Suite Scripts

This directory contains various utility scripts used by the CyberRDP Audit Suite for different testing and analysis purposes.

## Directory Structure

- `analysis/` - Scripts for analyzing test results and generating reports
- `capture/` - Scripts for capturing RDP traffic and sessions
- `legacy/` - Deprecated scripts kept for reference

## Available Scripts

### Analysis Scripts
- `analyze_rdp_security.py` - Main script for analyzing RDP security settings
- `generate_reports.py` - Generates comprehensive security reports
- `parse_gpo_results.py` - Parses Group Policy Object analysis results

### Capture Scripts
- `capture_rdp_session.ps1` - PowerShell script for capturing RDP sessions
- `monitor_rdp_connections.ps1` - Monitors active RDP connections

## Usage

Refer to the individual script headers for usage instructions and requirements.

## Dependencies

- Python 3.8+
- PowerShell 5.1+
